01 / Сначала задача

Что программа должна сделать

Получить длину числа m и сумму S. Вывести по возрастанию все m-значные натуральные числа, у которых цифры не повторяются и хотя бы две разные позиции дают сумму S.

Исходное условие и рабочая модель

В задании требуется «перечислить все натуральные числа m из 10-х разрядов, в которых цифры попарно различны и значения разрядов хоть в 1 паре дополняют друг друга». Параметры задаются опциями командной строки с контролем допустимости; предусмотрены значения по умолчанию и стандартный вывод.

Формулировка не фиксирует однозначно смысл m и сумму дополнения. Принятые в готовой программе соглашения: m — количество десятичных цифр, 2 ≤ m ≤ 10; S — 9 или 10. По умолчанию m = 4, S = 10. Это модель проекта, а не уточнённая цитата преподавателя.

Три условия для результата

  1. Первая цифра не равна нулю.
  2. Все m цифр попарно различны.
  3. Существуют позиции i < j, для которых di + dj = S.

Как понимать «хотя бы одну пару»

Пара может находиться в любых двух позициях, не обязательно соседних. Достаточно одного совпадения. Несколько пар внутри одного числа не создают несколько результатов.

1028 подходит при S=10; 1234 — нет; 1128 недопустимо из-за повторной 1; 0128 не четырёхзначное число.

Из теории нужны размещения без повторений

Порядок цифр важен: 1280 и 1820 — разные числа. Повторы запрещены. Поэтому объект перебора — упорядоченная выборка m различных элементов из десяти цифр, то есть размещение без повторений.

A10m = 10! / (10 − m)!

Генератор начинает и с размещений, у которых слева 0. Фильтр удаляет их. До проверки суммы остаётся:

Bm = A10m − A9m−1 = 9 · 9! / (10 − m)!

n! — факториал: произведение целых чисел от 1 до n, причём 0! = 1. При m=4 генератор рассматривает 5040 размещений, из них 4536 имеют ненулевую первую цифру.

Какие цифры дополняют друг друга

S = 10: {1,9}, {2,8}, {3,7}, {4,6}
S = 9: {0,9}, {1,8}, {2,7}, {3,6}, {4,5}

Пара 5 + 5 при S=10 не разрешена: две одинаковые цифры запрещены. Цифры 0 и 5 при S=10 могут присутствовать, но сами подходящую пару не образуют.

Главная идея алгоритма. Не идти по всем целым числам и не удалять повторы цифр после этого. Сразу строить размещения с различными цифрами в лексикографическом порядке; затем проверять только ведущий ноль и сумму пары.

next_permutation: ищем точку увеличения

Находим справа позицию, которую можно увеличить, сохраняя минимальный следующий порядок.

Как это устроено

  • Массив содержит все 10 различных цифр. Параметр int permutation[BASE] у функции фактически передаётся как указатель на первый элемент, а не как копия массива.
  • pivot = BASE - 2 начинает просмотр с предпоследнего индекса. Пока соседняя пара убывает, --pivot сдвигает поиск влево.

  • Если pivot < 0, весь массив убывает — это последняя перестановка. Функция возвращает false, ещё ничего не изменив.

05 / Логика решения

Почему результат полный и без повторов

Ближайшая следующая перестановка

Убывающий хвост уже максимален при неизменном префиксе: увеличить его перестановкой нельзя. Поэтому увеличивается самая правая возможная позиция — pivot. Ей подставляется минимально большая цифра, а хвост делается минимальным, возрастающим. Между старой и новой перестановками другой нет.

Ближайшее следующее размещение

Полные перестановки с одинаковыми первыми m цифрами образуют непрерывную группу в лексикографическом порядке. Дополнение по убыванию ставит нас в конец текущей группы. Один следующий полный порядок попадает в начало следующей группы; усечение даёт следующий размещённый префикс.

Стартуем с минимального 0,1,…,m−1. Каждый шаг строго увеличивает размещение, ничего не пропуская, пока не достигнуто максимальное. Поэтому все A10m размещений рассмотрены ровно один раз, и цикл завершается.

Фильтры дают именно нужные числа

Различие цифр уже обеспечивает генератор. Проверка первой цифры исключает записи меньшей длины. Вложенные циклы рассматривают все пары i<j и принимают число ровно тогда, когда хотя бы одна сумма равна S. Фильтры только удаляют неподходящие объекты; подходящие не пропускаются и не дублируются.

У записей одной длины с ненулевой первой цифрой лексикографический порядок совпадает с числовым. Удаление отдельных записей не нарушает порядок остальных, поэтому вывод возрастает.

Контрольный ответ 2376 — откуда он берётся

Для m=4, S=10 есть четыре возможные непересекающиеся пары. Зафиксировав одну пару, выбираем ещё две цифры из оставшихся восьми и переставляем четыре цифры. Затем вычитаем записи с ведущим нулём:

C82 · 4! − 7 · 3! = 28 · 24 − 42 = 630

Если число содержит две подходящие пары, оно посчитано дважды. Выбираем две пары из четырёх; все их цифры ненулевые и дают 4! порядков. По включению-исключению:

Q(4,10) = 4 · 630 − C42 · 4! = 2520 − 144 = 2376

Cnk = n! / (k! · (n−k)!) — количество сочетаний. Три пары потребовали бы шесть различных цифр, поэтому при m=4 дальнейших пересечений нет. Эти формулы нужны для проверки, но в C-программе не вычисляются.

Стоимость перебора

Переход размещения требует O(10) действий, поиск пары — не более m(m−1)/2 проверок. Обобщённо для алфавита размера n время без внешнего вывода: O(Anm · (n + m²)); формирование Q строк добавляет O(Qm).

В памяти остаётся только текущий объект и несколько коротких массивов: O(n), а при фиксированном n=10 — O(1). Рекурсии, динамического выделения памяти и хранения всего вывода нет. Режим подсчёта уменьшает объём вывода, но не количество размещений.

Символьные константы кодов цифр. Это не целые значения 0 и 9. Коды десятичных цифр в C расположены последовательно.
'\0' / '\n'
Нулевой символ завершает C-строку; перевод строки завершает одну строку вывода. Они не взаимозаменяемы.
%s / % + PRIu64
Форматные подстановки: %s — строка для fprintf, % и макрос PRIu64 — счётчик uint64_t для printf. В fputs символ % не имеет особого действия.
0, 1, 2, 4, 9, 10
Числовые литералы: 0 для начала индексов, сброса и успеха main; 1 для шага и ошибки вывода; 2 — минимум m и ошибка CLI; 4 — m по умолчанию; 9 — минимум S; 10 — основание и максимумы.

Три различия, которые нужно уметь объяснить. static у функции ограничивает её видимость при связывании. const ограничивает изменение через объявление. typedef создаёт имя типа. Эти конструкции решают разные задачи.
